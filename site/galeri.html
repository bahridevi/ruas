04

Cara pakai

Pasang lewat npm

React / Next.js: satu komponen per ikon; hanya ikon yang diimpor yang masuk ke bundel.

npm i @ruas-icons/react

import { MosqueDome } from "@ruas-icons/react";
<MosqueDome size={24} title="Masjid terdekat" />

Semua aplikasi: berkas SVG, sprite, CSS, dan data JSON.

npm i @ruas-icons/svg

@ruas-icons/svg/svg/mosque-dome.svg
@ruas-icons/svg/sprite.svg   #ruas-<id>
@ruas-icons/svg/ruas.css
@ruas-icons/svg/ruas.json
Paket React di npm Paket SVG di npm

SVG langsung, tanpa npm

Tempel SVG dari tombol Salin SVG, atau ambil berkasnya dari dist/svg/. Warna mengikuti color teks di sekitarnya.

Mode warna

Lisensi MIT: bebas dipakai, diubah, dan dijual. Atribusi di tampilan aplikasi tidak wajib, tetapi bila menyebarkan set ikon atau sebagian besarnya, sertakan teks lisensinya.

05

Ikut menyumbang

Ruas terbuka: siapa pun boleh mengusulkan atau menggambar ikon. Setiap kiriman diperiksa terhadap falsafah, otomatis dan oleh pemelihara, sebelum masuk galeri dan paket npm.

Usulkan, tanpa menggambar

Tulis nama, kegunaan, dan wujudnya. Foto atau sketsa sangat membantu.

Gambar sendiri

Baca Falsafah Ruas, fork repositorinya, tambahkan icons/<id>.svg dan icons/<id>.json, lalu kirim pull request. Penjaga berjalan otomatis.

Usulkan ikon Panduan menyumbang Lihat usulan GitHub

Perlu akun GitHub (gratis) untuk mengusulkan atau mengirim ikon.
